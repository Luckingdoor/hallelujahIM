# 扩展领域词库

给输入法补充医学、生物、法律等专业词汇。已经在词库里的词一律原样保留，只写入新词。

## 导入文件长什么样

纯文本，每行一条，TAB 分隔，后两列可以省略：

```
pembrolizumab	n. 帕博利珠单抗（PD-1 抑制剂）	ˌpembroʊˈlɪzuːmæb
optogenetics	n. 光遗传学
crispr
```

- `#` 开头是注释
- **只收单词**。带空格的多词术语（`myocardial infarction`）会被跳过——`words` 表是单词表，词组请用配置页上面的 Text-Expander
- 大小写不敏感，统一转小写
- 释义留空也能用，只是候选窗不显示中文（`Ctrl+\`` 开关翻译显示）

## 两种导入方式

### 页面上传（推荐）

打开 http://localhost:62718 ，找到 **Domain Dictionaries**：选文件、设频率、点 Import。
页面会显示新增了多少、多少已存在、多少被跳过，下面列出已导入的批次，点 `×` 可整批撤除。

### 命令行

```bash
python3 add-domain-words.py medical.txt --dry-run   # 先看会新增什么
python3 add-domain-words.py medical.txt            # 写入
python3 add-domain-words.py --list-added           # 看已导入的批次
python3 add-domain-words.py --remove medical.txt   # 撤除某一批
```

两种方式共用同一张记账表，混着用没问题。导入后重启输入法生效：`pkill -9 hallelujah`。

## frequency 怎么设

它**只影响同前缀候选之间的排序**，不决定词会不会出现。参考量级：

| 词 | frequency |
| --- | --- |
| the | 231 亿 |
| computer | 2.2 亿 |
| algorithm | 1600 万 |
| 词库中位数 | 9.1 万 |

默认 300000 落在全库前 25%~30%：输入 `optog` 时 `optogenetics` 排第一，而输入 `crisp` 时仍是 `crisp`、`crispy` 在前，专业词不会顶掉日常词。想让专业词更靠前就调大，但不建议超过 500 万。

## 词表从哪儿来

| 领域 | 资源 | 格式 |
| --- | --- | --- |
| 医学主题词 | MeSH（美国国立医学图书馆，免费） | ASCII `d20xx.bin`，用 `--format mesh` |
| 药品名 | RxNorm、DrugBank | CSV，用 `--format csv` |
| 生物/基因 | Gene Ontology `go-basic.obo` | OBO，用 `--format obo` |
| 蛋白质 | UniProt | TSV，用 `--format tsv` |
| 法律 | Cornell LII 词表、维基百科法律分类 | 多为纯文本 |

下下来的原始文件一般不能直接导入，用转换脚本处理：

```bash
# 每行一个词的纯文本
python3 convert-wordlist.py raw.txt --only-new -o medical.txt

# Gene Ontology
python3 convert-wordlist.py go-basic.obo --format obo --only-new -o bio.txt

# MeSH
python3 convert-wordlist.py d2025.bin --format mesh --only-new -o mesh.txt

# CSV，指定哪列是词、哪列是释义
python3 convert-wordlist.py terms.csv --format csv --word-col 0 --trans-col 2 -o out.txt
```

`--only-new` 会先跟现有词库比对，只留下真正缺的词——建议总是加上，能一眼看清到底新增多少。脚本还会自动去重、统一小写、剔除多词术语和不合词形的条目（纯数字、长度不足等）。

这些公开词库基本只有英文没有中文释义，导入后候选窗不显示翻译，但补全照常工作。

## 升级会不会冲掉

不会。`postinstall` 在覆盖词库前会先把导入的词导出来，复制完再灌回去，所以 pkg 升级既能拿到新版基础词库，又保住自定义词。用 `install.sh` 安装则完全不碰词库。
